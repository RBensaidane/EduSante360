## 📋 À Propos

**EduSanté360** est un site web moderne et complet dédié à l'éducation thérapeutique du patient diabétique. Il fournit un outil scientifique et pédagogique pour les professionnels de santé et les patients, basé sur les recommandations internationales (OMS, HAS, ADA, IDF).

### Objectifs

✅ Fournir un outil scientifique et pédagogique aux professionnels de santé  
✅ Offrir un référentiel académique sur les bases du diabète et de l'ETP  
✅ Harmoniser les pratiques éducatives à travers des recommandations internationales  
✅ Faciliter l'accès à l'information pour les patients et leurs proches

---

## 🎯 Public Cible

- 👨‍⚕️ Professionnels de santé (médecins, infirmiers, diététiciens, pharmaciens, psychologues)
- 🎓 Étudiants en sciences de la santé
- 🏥 Structures de soins souhaitant mettre en place des programmes d'ETP
- 👥 Patients diabétiques et leurs proches

## 📦 Installation

### Prérequis

- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- Éditeur de code (optionnel)

### Installation Locale

1. **Cloner le projet**
   ```bash
   git clone https://github.com/votre-username/edusante360.git
   cd edusante360
   ```

2. **Ouvrir le site**
   
   **Option A : Directement**
   ```
   Double-cliquez sur index.html
   ```
   
   **Option B : Avec un serveur local**
   ```bash
   # Avec Python
   python -m http.server 8000
   # Puis ouvrir http://localhost:8000
   ```

3. **C'est prêt !** 🎉
